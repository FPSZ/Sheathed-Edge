# AWDP Blue Web Training Set

This file collects supervised blue-team training cases for AWDP web repair.

Training target:

- patch the proven exploit edge
- preserve service behavior
- obey the minimum-change law

Supervision format for every case:

- vulnerable edge
- smallest patch boundary
- patch sketch
- why broader fixes are rejected
- minimum regression check

- `ciscn-finals-web-mediadrive`
- `ciscn-finals-web-easy-time`
