# AWDP Blue PWN Training Set

This file collects supervised blue-team training cases for AWDP binary service repair.

Training target:

- patch the proven exploitation edge
- preserve service availability
- obey the minimum-change law

Supervision format for every case:

- vulnerable edge
- smallest patch boundary
- patch sketch
- why broader fixes are rejected
- minimum regression check
