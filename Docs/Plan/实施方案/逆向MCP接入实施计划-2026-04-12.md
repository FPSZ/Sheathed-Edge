# 逆向 MCP 接入实施计划（IDA 9.1 / radare2 第一批）

## Summary
- 当前主链固定为 `Open WebUI -> Gateway -> Tool Router -> MCP runtime`，不改架构拓扑。
- 第一批优先接入 `radare2` 与 `IDA Bridge`：
  - `radare2` 直接作为可启用 MCP 接入。
  - `IDA Bridge` 先按 `IDA 9.1` 实际环境登记与授权，等 IDA 打开并启动插件后再启用。
- 语言策略固定为：
  - `Rust`：Tool Router、MCP runtime、动态 discover/execute、日志与权限控制。
  - `Go`：Gateway、Admin、Open WebUI preview、用户授权与控制面。
  - `Python`：仅用于必须嵌进分析器本体的桥接层，尤其是 `IDA 9.1` 的 `IDAPython` 插件。

## Why IDA Version Matters
- `IDA` 能不能接入 `MCP`，核心不取决于 9.0 还是 9.1，而取决于是否有可用的插件或桥接入口。
- 版本仍然重要，因为它会影响：
  - 安装目录与脚本路径
  - `IDAPython` 版本
  - 插件兼容性
  - 默认端口与启动方式
- 当前实际环境以 `IDA 9.1` 为准：
  - 安装目录：`D:\CTF\tool\SURBIFByb2Zlc3Npb25hbCA5LjE`
  - 已发现插件：`plugins\mcp-plugin.py`
  - 已发现 Python：`python311\python.exe`

## First Batch
### 1. radare2
- 服务器类型：`mcpo_stdio`
- 可执行入口：`D:\CTF\tool\mcp\radare2-mcp\local\bin\r2mcp.exe`
- 工作目录：`D:\CTF\tool\mcp\radare2-mcp`
- 默认先挂到 `pwn` scope，服务 reverse/pwn 二进制分析。
- 本轮要求打通：
  - MCP server 注册
  - discover tools
  - 用户授权
  - Open WebUI preview
  - Qwen 端到端调用

### 2. IDA Bridge
- 服务器类型：`native_streamable_http`
- 目标 URL：`http://127.0.0.1:13337/mcp`
- Bridge 由 `IDA 9.1` 内部插件 `plugins\mcp-plugin.py` 提供。
- 语言分层固定为：
  - `IDAPython`：驻留在 IDA 内部，暴露 MCP 入口。
  - 外层系统继续由 `Go + Rust` 管理，不把主控制链写回 Python。
- 本轮先完成：
  - 按 `IDA 9.1` 真实路径登记 profile
  - 用户授权
  - 文档化启动方式
- 本轮不默认启用：
  - 因为只有在 IDA 已打开且插件服务已启动时，`native_streamable_http` 才会通过验证
