# Reverse Triage Checklist

## 最小事实

- 输入路径是否真实存在
- 是单文件还是压缩包
- 主要入口文件是什么
- 预期平台是什么
- 预期 flag 形式是否已知

## 快速分类

- `PE / ELF / .NET / Unity / APK / script / data`
- `x86 / x64 / arm / unknown`
- 是否有明显壳或打包痕迹
- 是否带资源目录、配置、脚本、库文件

## 第一轮高信号证据

- 程序提示字符串
- 导入库或运行时特征
- 关键资源文件名
- 明显比较/校验/解密迹象

## 第一轮输出

- 当前题型判断
- 当前最有价值的入口
- 下一步建议 skill / 工具
